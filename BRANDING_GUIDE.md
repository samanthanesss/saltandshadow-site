## Typography

### Primary Font: Playfair Display
- **Usage:** Headings, titles, brand mark
- **Weight:** 400 (Regular), 500 (Medium), 600 (Semibold)
- **Family:** Serif
- **Import:** Google Fonts
- **Character:** Elegant, editorial, sophisticated

**Sizes:**
- Brand Mark (Hero): clamp(2.8rem, 7vw, 4.2rem)
- Page Title: clamp(2.25rem, 6vw, 3.4rem)
- Feature Card Heading: clamp(1.65rem, 4vw, 2.15rem)
- Section Heading: clamp(1.65rem, 4vw, 2.2rem)

### Secondary Font: Inter
- **Usage:** Body text, navigation, labels, UI elements
- **Weight:** 300 (Light), 400 (Regular), 500 (Medium), 600 (Semibold)
- **Family:** Sans-serif
- **Import:** Google Fonts
- **Character:** Clean, modern, highly readable

**Sizes:**
- Body Text: 0.9rem
- Navigation: 0.8rem
- Labels: 0.72rem
- CTA/Button: 0.92rem

### Line Heights
- Body: 1.72
- Compact Content: 1.56
- Headings: 0.94–0.98

## Design System

### Spacing Scale
- **Small (xs):** 8px
- **Small-Medium (sm):** 12px–14px
- **Medium (md):** 18px–22px
- **Large (lg):** 28px–32px
- **Extra Large (xl):** 40px–52px

### Border Radius
- **Small:** 6px–8px
- **Medium:** 12px
- **Large:** 18px
- **Extra Large:** 28px

### Grid & Layout
- **Max Page Width:** 1140px
- **Narrow Content Width:** 930px
- **Prose/Text Max Width:** 760px
- **Grid Columns (Desktop):** 2 columns
- **Grid Gap:** 14px–22px
- **Padding (Mobile):** 14px–16px

### Breakpoints
| Device | Width | Layout |
|--------|-------|--------|
| Mobile | < 640px | 1 column, single-column layouts |
| Tablet | 640px–900px | 2 columns → 1 column, adjusted spacing |
| Desktop | > 900px | Full 2-column grid, max content width |

### Transitions
- **Standard Duration:** 220ms
- **Easing:** ease
- **Properties:** color, opacity, transform, border-color, background-color

## Usage Guidelines

### Color Usage
- **Primary Action:** Navy (#304B70)
- **Hover/Focus:** Navy Bright (#44648E)
- **Background:** #F2F1EF (clean, minimal)
- **Text:** Black (#000) for maximum readability
- **Dividers:** Light opacity navy (0.08)

### Typography Usage
- **Headlines & Titles:** Playfair Display (serif elegance)
- **Body & Interface:** Inter (clean, modern readability)
- **Maintain hierarchy:** Size, weight, spacing create visual structure

### Spacing
- Use grid-based spacing (multiples of 8px where possible)
- Leave generous breathing room around content
- Reduce spacing on mobile devices
- Maintain visual hierarchy through spacing

### Imagery
- Keep aspect ratios consistent within sections
- Use 8px border radius on images
- Maintain high quality
- Consider composition and framing
